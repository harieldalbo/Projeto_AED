# Análise Exploratória e Estatística de Vendas

Projeto de análise de dados desenvolvido em Python com o objetivo de analisar o comportamento das vendas de uma loja de varejo, utilizando técnicas de Estatística Descritiva e Estatística Inferencial.

O projeto busca responder perguntas de negócio relacionadas a vendas, produtos, promoções, sazonalidade, perfil dos clientes e períodos comerciais como Black Friday e Natal.

---

## Objetivo

O objetivo deste projeto é analisar os dados históricos de vendas da loja e transformar os resultados estatísticos em informações úteis para a tomada de decisões da equipe de marketing.

A análise combina:

- Estatística Descritiva;
- Análise exploratória de dados (EDA);
- Visualização de dados;
- Análise de correlação;
- Identificação de outliers;
- Testes de hipóteses;
- Testes A/B;
- Intervalos de confiança de 95%;
- Interpretação dos resultados no contexto do negócio.
